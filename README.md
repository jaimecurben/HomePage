# HomePage - Réplica de Apple

Este proyecto es una maquetación profesional que replica la página de inicio de **Apple**, enfocada en la precisión visual, el diseño responsivo y el uso de tecnologías web modernas.

## 🚀 Tecnologías Utilizadas

*   **HTML5**: Estructura semántica y clara.
*   **CSS3**: Estilos personalizados divididos de forma modular (`header`, `footer`, `main`).
*   **Bootstrap 5.3**: Utilizado para el sistema de rejilla (grid), componentes responsivos y navegación.
*   **JavaScript**: Integración con los componentes interactivos de Bootstrap.

## 📋 Características Principales

*   **Diseño Responsivo**: La página se adapta perfectamente a dispositivos móviles, tablets y escritorio.
*   **Navegación Apple-Style**: Menú superior dinámico con logotipos e iconos característicos.
*   **Footer Inteligente**: Sistema de navegación complejo que se transforma de columnas (desktop) a un sistema de acordeones (mobile).
*   **Secciones de Producto**: Maquetación fiel de las secciones Hero y Grid de Apple, incluyendo iPhone, Mac y Watch.
